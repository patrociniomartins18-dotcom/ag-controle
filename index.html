    mapMapa de entregas (Google Maps)

    Por padrão o app usa um mapa gratuito (Esri). Para usar o Google Maps — mais preciso para achar o número exato da casa — cole abaixo uma chave de API do Google. A chave é compartilhada com os aparelhos que têm login (para o mapa funcionar no celular) e não entra nos backups.

    Como conseguir a chave (passo a passo)
    1. Acesse console.cloud.google.com, crie um projeto e ative o faturamento (o Google exige um cartão; existe uma cota mensal gratuita — confira os valores atuais na página de preços do Google Maps Platform).
    2. Em "APIs e serviços" → "Biblioteca", ative a Maps JavaScript API, a Geocoding API e a Places API (New) (esta última dá as sugestões de endereço enquanto você digita).
    3. Em "Credenciais", crie uma chave de API. Como o app abre direto do arquivo, restrinja a chave por API (só essas três) em vez de por site, e defina um orçamento/alerta de gasto.
    4. Cole a chave acima, clique em Salvar chave e depois em Testar.

    Importar dados históricos da planilha

    Importa os 57 produtos cadastrados e os 222 pedidos já lançados na planilha original (maio a agosto de 2026). Pode ser feito apenas uma vez para evitar duplicar lançamentos.

    Restaurar produtos (maio a julho)

    Recadastra qualquer produto de maio/junho/julho que tenha sido excluído (e corrige o custo dos que estiverem com valor diferente da planilha original). Isso conserta o lucro de vendas antigas que ficou errado após excluir produtos. Pode rodar quantas vezes quiser — não duplica.

    Corrigir saídas de custo

    Verifica todas as vendas já recebidas: recria no Caixa qualquer saída de "Compra de Mercadoria" ou "Despesas Fixas" que esteja faltando, e corrige a data das que já existem para ficar igual à data da entrada correspondente. Rode isso depois de "Restaurar produtos". Pode rodar quantas vezes quiser — não duplica.

    Backup

    Todos os dados ficam salvos apenas neste navegador. Exporte um backup regularmente para não perder informações.
